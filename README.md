# Sumine 澄音

一个浏览器端 MIDI 钢琴原型：导入 MIDI 文件后播放声音并显示瀑布流，也可以连接 USB MIDI 键盘实时演奏。

## 运行

```bash
npm install
npm run dev
```

使用 Chrome 或 Edge 打开本地地址。连接硬件时点击“连接设备”并允许 MIDI 权限。部署时需要 HTTPS 才能使用 Web MIDI。

## 已实现

- `.mid` / `.midi` 文件选择和拖放导入
- 播放、暂停、拖动进度、速度和音量控制
- 切换到后台后继续播放，返回页面时自动同步进度
- 88 键瀑布流、左右音区配色、琴键同步高亮
- Web MIDI 输入和力度响应
- 屏幕琴键点击演奏
- 演奏、曲库、练习和设置的顶部页面导航
- 文件完全在浏览器本地处理

## 推荐路线图

1. 练习：左右手拆分、等待正确音符、A-B 循环、节拍器、速度递增。
2. 反馈：错音/漏音/节奏判定、分段评分、练习历史。
3. 乐谱：MusicXML 导入、五线谱同步、指法标注。
4. 音色：可加载 SoundFont、延音踏板、MIDI 输出与录音回放。
5. 创作：音符编辑、粒子/灯光主题、摄像头叠加、竖屏与 4K 视频导出。
